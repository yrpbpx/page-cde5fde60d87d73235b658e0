01 / 方案说明

牧牛提供的是一套按额度分档的网络访问方案

定价结构简单：按月或按年付费，换取每月固定流量额度与固定数量的同时在线设备名额。三档之间的差别只在额度、设备数与附加能力，不涉及使用方式的变化。

计费单位

按“每月流量 + 同时在线设备数”计量

套餐的核心参数只有两个：每月可用流量，以及允许同时保持在线的设备数量。流量按月重置，设备数指同一时刻处于连接状态的终端上限，不是累计添加过的设备总数。

超出流量额度后的处理方式，本页不作额外承诺；如需了解，请以你实际购买时看到的条款为准。

付费周期

月付与年付并行，年付按十个月计

三档套餐都提供月付与年付两种周期。年付价格是月付价格的十倍，相当于按十个月计费、覆盖十二个月。选择年付前，建议先按月付使用一段时间，确认额度与设备数适合自己的实际使用节奏。

升级路径

档位之间只上调额度，不改变操作方式

基础版、旗舰版、团队版的客户端安装与配置流程完全一致，升级后无需重新学习使用方法。差异体现在流量上限、同时在线设备数量，以及团队版提供的企业定制路由与专属对接。

  • 只在一两台设备上使用、以浏览与影音为主：基础版的额度通常够用。
  • 多设备并用、需要更宽裕的流量与更多同时在线名额：考虑旗舰版。
  • 多人协作、需要统一配置与对接人：团队版更为合适。

03 / 客户端

客户端按设备类型分开安装，三档共用同一套流程

牧牛的配置方式是“获得连接信息 → 在对应客户端中导入 → 开启连接”。不同系统的操作路径略有差异，下面按平台分别说明。下载地址以你购买后获得的渠道为准，本页不提供下载链接。

桌面端

Windows 与 macOS

在桌面端安装客户端后，用购买时获得的连接信息完成导入，导入成功后列表里会出现可用的线路条目，选中并开启连接即可。

桌面端支持随系统启动与后台驻留，适合长期保持在线的使用方式。若一台电脑需要切换不同网络环境，建议为每个环境保留独立的配置条目，避免反复覆盖。

移动端

iOS 与 Android

移动端在首次开启连接时需要授予系统级网络配置权限，这是系统层面的要求，与是否信任某款应用无关。授权后即可在应用内选择线路并开启。

移动设备切换 Wi-Fi 与蜂窝网络时可能短暂断开，属正常现象，重新连接即可。若长期不用，建议在应用内主动断开，避免后台占用同时在线名额。

路由与共享

在路由器上使用

若希望整个局域网共用一条连接，可在支持相应功能的路由器上配置。此时所有接入该路由的设备会共用同一个出口，也会共同占用套餐的同时在线名额。

团队版的定制路由能力面向有统一出口需求的场景，具体配置项需要在开通后与对接人确认，本页不作展开。

名额管理

同时在线设备怎么算

同时在线名额按“当前处于连接状态的设备”计数。同一台设备在多个客户端重复登录，可能被计为多个连接；退出登录或主动断开后，名额释放。

若出现名额已满的提示，先检查是否有旧设备仍在后台保持连接，而不是直接升级套餐。

04 / 使用步骤

从零开始，按四步完成配置

以下顺序适用于三档套餐。如果中途出现问题，先回到上一步确认，再继续往下走。

确认档位与额度

先估算自己每月的实际用量与常用设备数量，再对照套餐一节的三档参数选择。设备数按“同时在线”计算，不是按历史添加过的设备总数，这一点容易高估需求。

不确定时先选低一档，按月付观察一到两个计费周期，再决定是否调整。

安装对应平台的客户端

按你的设备类型选择桌面端或移动端客户端安装。安装来源以你购买后获得的渠道为准，不要从来源不明的页面获取安装包。

移动端首次连接会请求系统权限，这是正常流程；拒绝授权会导致连接无法建立。

导入连接信息并保存

用购买时获得的连接信息在客户端内完成导入。导入成功后，建议先保存为命名清晰的配置条目，便于日后在不同网络环境之间切换。

这些连接信息等同于凭证，不要转发给他人，也不要粘贴到公开页面。

连接、验证、再使用

选择线路并开启连接，随后打开一个常用页面确认访问正常，再开始正式使用。若无法访问，按常见问题一节的排查顺序逐项确认，不要同时改动多个设置。

日常使用中如遇明显变慢，可先切换线路再观察，避免误判为账号问题。

05 / 常见问题

按主题分组的常见问题

分为四组：计费与额度、设备与名额、安装与连接、支持与沟通。每组内的问题独立作答，不依赖前文。

主题一

计费与额度

年付和月付的差别只有价格吗？
在本页展示的内容范围内，年付与月付的权益项一致，区别在于计费周期与总价。年付金额为月付金额的十倍，覆盖十二个月，相当于按十个月计费。若你还不确定长期使用，建议先按月付。
每月流量什么时候重置？
流量按月度周期计算并重置。具体的重置时点与你下单的时间相关，本页不额外规定。重置后未用完的部分不累积到下一周期。
当月流量用完了会怎样？
本页不对超出额度后的处理方式作出承诺，以免与实际条款不一致。遇到这种情况，请以你购买时看到的条款为准，或在下单前的说明中确认清楚再决定档位。

主题二

设备与名额

三档套餐分别能同时在线几台设备？
基础版 3 台、旗舰版 5 台、团队版 20 台。这里的数量指同一时刻处于连接状态的设备上限，不是累计可以添加的设备总数。
同一台设备装了两个客户端，算几个名额？
通常按当前处于连接状态的连接数计算，因此同一台设备在两处同时保持连接可能被计为多个。日常使用中建议只保留一个客户端处于连接状态。
提升设备数量只能换档吗？
在本页列出的三档方案中，同时在线名额与档位绑定，提高名额的方式是选择更高一档。是否支持其他调整方式，本页不作说明。

主题三

安装与连接

连接不上，第一步该检查什么？
先确认导入的连接信息完整、未过期，再确认设备本身的网络是通的。这两项都正常后，再尝试更换线路。一次只改一个变量，便于判断真正的原因。
移动端提示需要授予权限，可以拒绝吗？
可以拒绝，但连接将无法建立。该权限是系统层面的要求，用于把设备的网络流量交给客户端处理。授权后如不再使用，可在系统设置中撤销。
为什么切换 Wi-Fi 后会短暂断开？
设备在网络之间切换时，连接需要重新建立，短暂中断属正常现象。等待重新连接完成即可，若长时间未恢复，可手动断开后再次连接。
连接信息可以分享给同事吗？
不建议。连接信息等同于账号凭证，分享出去会让对方占用你的同时在线名额，也无法追溯使用情况。多人协作的场景应选择团队版并统一管理。

主题四

支持与沟通

旗舰版的优先工单支持指什么？
按本页套餐所列内容，旗舰版包含 7×24 优先工单支持，即提交工单时可获得优先处理次序。具体的响应时限本页不作承诺，以免与实际执行不一致。
团队版的专属客户经理负责哪些事？
按本页套餐所列内容，团队版提供专属客户经理，作为统一对接人。是否覆盖配置协助、额度规划等具体事项，需要在开通后与对接人确认，本页不作展开。
提交问题时怎样描述更快被处理？
提供四类信息：使用的套餐、设备系统与客户端版本、问题出现的具体操作步骤、以及能否稳定复现。信息齐全的工单通常能省去一轮反问。
